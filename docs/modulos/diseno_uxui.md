# Módulo — Diseño UX/UI

### 1. Principios de Experiencia de Usuario

* **Canal Conversacional (WhatsApp):**
  * Uso prioritario de componentes interactivos nativos (Listas y Botones de respuesta rápida) para minimizar errores de digitación.
  * Mensajes claros, concisos y formateados con negritas y emojis que faciliten la lectura rápida.
  * Respuestas amigables ante fallos de formato, ofreciendo siempre la opción de reiniciar con la palabra `"menú"`.

* **Aplicación Web (Administración y Recepción):**
  * Diseño responsivo adaptado tanto a pantallas de escritorio en recepción como a dispositivos móviles para administración remota.
  * Uso de códigos de colores semánticos para los estados de habitación (Verde = Disponible, Rojo = Ocupada, Amarillo = Limpieza, Gris = Mantenimiento).
  * Feedback visual inmediato en operaciones críticas (notificaciones Toast y confirmaciones modales para cancelaciones).
